# Учебные дисциплины

Организация предназначена для хранения, систематизации и сопровождения учебных материалов, лабораторных работ, практических заданий и проектов по различным дисциплинам.

## 📚 Дисциплины

|Индекс|Дисциплина|
|---|---|
|`OOP`|Объектно-ориентированное программирование|
|`DB`|Базы данных|
|`TProg`|Теория программирования|
|`OS`|Операционные системы|
|`MP`|Микропроцессорная техника|
|`IoT`|Интернет вещей|
|`WEB`|Веб-разработка|
|`ASOIU`|Автоматизация и системы управления|

## 📁 Структура

Каждая дисциплина представлена отдельным репозиторием или группой репозиториев, содержащих исходный код, отчёты, документацию и другие необходимые материалы.

## 🎯 Цель

Создание единого пространства для хранения учебных работ, удобной навигации по дисциплинам, сохранения истории изменений и дальнейшего развития проектов.
